Projectes

  • Futbolí amb Home Assistant

    2026 · ESPHome · WLED · Home Assistant

    Un futbolí Córdoba antic i restaurat que compta els gols tot sol. Unes barreres d'infrarojos als carrils avisen un ESP32 que du la partida, i Home Assistant la converteix en un marcador d'estadi a la tauleta, amb locutor, música i control per veu. Les tires LED celebren cada gol. Tot va amb bateria i amagat dins el moble, sense tocar la porteria.

    Com funciona GitHub

  • Ars Domus

    2026 · three.js · Claude Code

    Ca teva en 3D a partir d'un plànol, unes fotos i dades públiques del terreny, per passejar-hi dins el navegador. Guarda la casa actual i una proposta de reforma, i es canvia d'una a l'altra sense moure la càmera. No es modela res a mà: Claude Code converteix les fonts en dades i three.js les dibuixa.

    Demo GitHub

  • Ball Radar

    2026 · Flutter · Android

    Una gimcana GPS per jugar a l'aire lliure. Algú amaga les 7 esferes caminant per un parc o pel barri, i la resta les ha de trobar guiant-se pel radar. Feta amb Flutter per a Android.

    Google Play Vídeo

  • Bombshot

    2026 · Home Assistant · Python

    Jocs de festa que funcionen sencers dins un altaveu Home Assistant Voice PE, sense mòbil ni pantalla. A la bomba, l'altaveu diu un nombre, comença un tic-tac de 30 segons i s'ha d'endevinar quin cable tallar. El Tòtem del Xaman és un Simon de quatre elements amb llums i veu.
