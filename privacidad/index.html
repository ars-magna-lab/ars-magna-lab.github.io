Política de privacidad

Qué datos usan esta web y las herramientas con las que Edu Herraiz gestiona el canal de YouTube Ars Magna Lab.

Esta web

No usa cookies ni rastreadores, y el autor no recoge datos de quien la visita. Se sirve con GitHub Pages y carga las fuentes de Google Fonts, que como cualquier servidor reciben la dirección IP del visitante.

Las herramientas del canal

Ars Magna Lab tiene una aplicación propia que se conecta a la API de YouTube. La usa solo su autor, y solo con su propio canal, para consultar sus vídeos y listas y para actualizar títulos, descripciones, subtítulos, miniaturas y listas. No está abierta a otras personas.

Pide estos dos permisos de la cuenta de Google: youtube.force-ssl (ver y gestionar el canal) y youtube.upload (subir vídeos).

Qué datos trata y dónde están

Solo los datos del propio canal: sus metadatos, vídeos y transcripciones. El token de acceso se guarda en el ordenador del autor. Los datos del canal se guardan allí y en copias privadas suyas.

El autor puede usar herramientas de IA para redactar títulos, descripciones y traducciones a partir de esos datos. No se venden ni se comparten con fines publicitarios.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde los permisos de la cuenta de Google.

Al usar la API se aplican también las Condiciones de YouTube y la Política de privacidad de Google.
